# 模板

复制使用，删掉不需要的行。命名与编号规则见 `AGENTS.md` §11。

## 编号任务清单（阶段 1 产出，交给用户确认）

```markdown
## 任务清单：<一句话目标>
轨道：轻轨 / 标准轨 / 重轨（动冻结件：<列出>）

结论：<一句话说明为什么这么做，代价是什么>

| # | 做什么 | 完成的判据（可复跑的证据 / 需同步的文件） | 影响面 |
| --- | --- | --- | --- |
| 1 | <改动点> | `mvn -o clean test` 用例 X 通过 / 契约 §Y 已同步 | <文件:行> |
| 2 | <契约同步> | `04-check-contracts.py` 退出码 0 | contracts/... |
| 3 | <验证复跑> | `05-verify-authz.py` 越权 0 例，报告新增第 N 行 | reports/... |
| 4 | <证据写回> | ADR-0xx 或 backlog #n 行存在且字段齐 | decisions/... |

不做：<明确排除项与原因>
风险与代价：<性能/复杂度/兼容性；需要用户签字的点>
门禁时机：<是否包含 10/12/13 这类会启停容器的步骤>
```

## ADR（`p0/decisions/ADR-0nn-标题.md`）

```markdown
# ADR-0nn <标题：取舍而不是功能名>

状态：提案 / 已采纳 / 已知缺陷 / 阻断项 / 待验证
日期：<YYYY-MM-DD>
决策者：<角色>

## 背景与约束
<为什么现在必须决定；引用现有门槛或报告编号>

## 决策
<一句话结论 + 关键取舍点，逐条列出>

## 代价
<放弃了什么、性能/复杂度/运维负担、不可逆的部分>

## 证据
<必须能被下面这份东西推翻或证实：报告路径 + 断言编号 + 执行命令 + 复跑日期>
- `p0/evaluation/reports/xxx.md` 的 <断言行>
- 复跑：`python p0/scripts/0n-xxx.py`

## 复测与失效条件
<什么情况下这条决策作废，谁负责复测，日期>
```

没有证据的写"待验证"，不写 ADR 正文结论。

## P1-backlog 行（`p0/decisions/P1-backlog.md`）

```markdown
| <新编号> | 阻断/高/中/低 | <事项，一句可执行的话> | ADR-0nn / <报告>FD-xx / 契约评审 | <一条可复跑的证据：命令 + 判据> | <责任人角色> | YYYY-MM-DD |
```

编号一经登记不再变动；新项按级别插入对应分组末尾，因此编号不连续递增。

## 状态用词（不要自创）

| 用词 | 含义 | 用在 |
| --- | --- | --- |
| 已实现并验证 | 代码 + 证据都有 | 落地说明 §1、backlog 关闭 |
| 已实现，引擎侧未联调 | 代码在，外部依赖未接 | 落地说明（如 WeKnora 适配） |
| 已知缺陷 | 实现与契约不符，且有报告编号 | ADR 状态、backlog |
| 阻断项 | 不关闭不能进入试点 | ADR 状态、backlog 级别 |
| 【实现未达成】 | 契约是目标，现状不是 | 契约文档正文，禁止当现状编码 |
| 待验证 | 没有证据，只有推断 | ADR 状态栏 |
