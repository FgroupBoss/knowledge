# P0 Go / No-Go 决议

- 决议：**Conditional Go**（2026-11-01）
- 判定依据：4 条硬门槛全部达成，其中 1 条带韧性例外；4 项目标门槛全部达标，另有 2 项能力实测不达标并已成 ADR；
  引擎仍是我方自实现的检索层（非 WeKnora 本体），因此**不得迁移正式数据、不得对外承诺生产 SLA**。
- 签署范围：本决议只覆盖 P0 验证环境（单机、本机生成语料、单实例门户）。任何外推到生产都要重新评审。

## 4. 这套结论不能用来做什么（同等重要）

1. **不能当作生产检索质量**：语料是本轮按体裁自建的脱敏文档，每份主体词彼此唯一、问题原样携带主体词，
   这是刻意的上界测试；它证明链路与权限正确，不证明在真实分布上的召回。
2. **不能当作生产容量**：单机、GPU 独占、限流阈值在评测时放宽过（`P0_CHAT_RATE_PER_MIN=400`、
   `P0_MODEL_MAX_PROMPT_CHARS=6000`，仓库默认 30/分钟与 4096）。对比任何指标必须注明口径。
3. **不能当作灾难恢复能力**：演练是同机旁路恢复到临时库，未验证跨机、独立介质、加密与不可变保留，无实测 RPO/RTO。
4. **不能当作"无依据会拒答"**：见 E2。
5. **不能把 P0 代码当生产代码扩写**：验证代码里可复用模块要迁入正式工程并重新评审（方案第 10 节）。

## 5. 达成项（不需要签署，但常被误问）

- 契约已冻结：OpenAPI 17 路径/19 操作/17 组件、4 份 Kafka JSON Schema 与样例、状态机、21 个错误码、配置项目录；
  `04-check-contracts.py` 校验 0 error（4 条 warning 全部是"schema 里的可选字段生产端未发出"）。
- 数据模型无外键、`CHAR(36)` 主键、`DATETIME(3)` UTC 三件套已定稿（ADR-005），迁移副本与执行源逐文件 SHA-256 相符。
- 审计链路可判定：`ALLOW/DENY` 全量落库，撤权后引用立刻不可读，越权尝试 0 成功。
- 原件是唯一权威、索引是可重建派生物（FD-13/FD-14 双向证明：删索引不删原件，原件可逐字重建索引）。
